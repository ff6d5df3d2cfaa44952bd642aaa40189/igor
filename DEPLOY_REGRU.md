# Деплой на REG.RU (shared-хостинг)

Эта версия сайта полностью самодостаточная: весь CSS и JS встроен в `index.html`.

## Что загрузить на хостинг

Достаточно одного файла:

- `index.html`

## Куда загрузить

В корневую папку сайта в ISPmanager:

`/www/<ваш-домен>/`

## Проверка

1. Откройте `https://<ваш-домен>/`
2. Должна открыться страница каталога с фильтрами.
3. Поиск и фильтры должны сразу работать без дополнительных файлов.
