# Чеклист деплоя в ISPmanager (REG.RU) — 10–15 минут

> Цель: развернуть статическую сборку сайта и включить отправку заявок через `api/leads.php`.

## 0) Что должно быть заранее

- Домен уже добавлен в ISPmanager.
- SSL для домена уже выпущен (или выпустите после шага 8).
- Локально у вас есть этот репозиторий.

---

## 1) Собрать сайт локально

В терминале на вашем компьютере:

```bash
npm install
npm run build
```

После этого появится папка `out/`.

Проверьте, что внутри `out/` есть:

- `index.html`
- папки `catalog/`, `chat/`, `region/`, `city/`, `district/`, `moscow-ao/`
- `api/leads.php`
- `data/leads.json`

---

## 2) Открыть правильную папку сайта в ISPmanager

1. Слева нажмите **Менеджер файлов**.
2. Откройте каталог: `/www/<ваш-домен>/`.
3. Если там лежат старые файлы сайта — выделите их и удалите (или перенесите в backup-папку).

---

## 3) Загрузить файлы сборки

Есть 2 удобных варианта:

### Вариант А (рекомендую)
1. На компьютере заархивируйте **содержимое** папки `out/` в `out.zip`.
2. В ISPmanager нажмите **Загрузить** и загрузите `out.zip` в `/www/<ваш-домен>/`.
3. Выделите архив и нажмите **Извлечь**.

### Вариант Б
- Загрузите все файлы/папки из `out/` напрямую в `/www/<ваш-домен>/`.

⚠️ Важно: в корне домена должен лежать `index.html`, а не папка `out`.

---

## 4) Проверить структуру после загрузки

В `/www/<ваш-домен>/` должны быть:

- `index.html`
- `_next/`
- `catalog/`, `chat/`, `region/`, `city/`, `district/`, `moscow-ao/`
- `api/leads.php`
- `data/leads.json`

---

## 5) Выставить права для записи заявок

В ISPmanager:

1. Откройте папку `data`.
2. Для `data/leads.json` выставьте права минимум **664**.
3. Для папки `data` выставьте права минимум **755** (если не пишет — **775**).

Если есть пункт владельца/группы — оставьте владельцем вашего пользователя хостинга.

---

## 6) Проверить, что PHP работает

1. Откройте в браузере:
   `https://<ваш-домен>/api/leads.php`
2. Нормально, если вы увидите JSON с ошибкой метода (`Method not allowed`) — это значит файл PHP выполняется.

---

## 7) Проверить отправку формы

1. Откройте любую страницу ЖК: `https://<ваш-домен>/chat/.../`
2. Отправьте тестовую заявку.
3. В ISPmanager откройте `data/leads.json` и убедитесь, что добавилась новая запись.

---

## 8) Если заявки не пишутся

Сделайте по порядку:

1. Проверьте права `data/leads.json` и `data/` (шаг 5).
2. Проверьте, что `leads.json` не пустой файл, а корректный JSON-массив (минимум `[]`).
3. Проверьте, что путь именно `/api/leads.php` доступен по HTTPS.
4. Посмотрите логи PHP/сайта в ISPmanager (раздел «Журналы посещений» / «Журналы WWW-запросов»).

---

## 9) Быстрый smoke-тест после релиза

- Главная открывается.
- `/catalog/` открывается.
- Фильтры на `/catalog/` меняют выдачу.
- Любая карточка `/chat/.../` открывается.
- Форма отправляется и пишет запись в `data/leads.json`.
- `https://<домен>/sitemap.xml` и `https://<домен>/robots.txt` открываются.

---

## 10) Обновление сайта в будущем

Каждый раз:

1. `npm run build`
2. Перезагрузить свежие файлы из `out/` в `/www/<домен>/`.
3. Не удалять `data/leads.json` (иначе потеряете собранные заявки).
